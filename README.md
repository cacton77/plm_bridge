# plm_bridge

Connects a ROS 2 inspection cell to product lifecycle management (PLM) systems:
a local parts catalog synced from one or more PLM backends, CAD loading, and
upload of inspection plans and results.

Work in progress: the code is being extracted from ViewpointGeneration's
`catalog/` package on its `plm-bridge` branch. See `REPORT.md` once it exists.
